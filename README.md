# Personal Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript, featuring video backgrounds and visual elements to showcase projects, skills, and background.

## Features

- Animated/video background (earth and flow visuals)
- Profile photo and personal introduction
- Custom styling and interactive elements via JavaScript
- Fully responsive, framework-free front end

## Project Structure

```
├── index.html             # Main portfolio page
├── style.css               # Styling
├── script.js                 # Interactivity/animations
├── earth.jpg                  # Background image
├── earth.mp4                   # Background video
├── flow.mp4                     # Additional background video
└── profile photo.jpeg             # Profile picture
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/kjnoha/portfolio.git
   ```
2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   npx serve .
   ```
3. View and customize the portfolio with your own content, projects, and media.

## Tech Stack

- **HTML** — structure
- **CSS** — styling and layout
- **JavaScript** — interactivity and dynamic effects
